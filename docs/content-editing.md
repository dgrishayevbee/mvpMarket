# Редактирование контента главной страницы

Весь контент главной/каталога (заголовки, карточки решений, тарифы, готовые
пакеты, AI-баннер, футер) вынесен из кода в единый объект —
`src/data/siteContent.js` (дефолты) + `src/context/ContentContext.jsx`
(состояние + правки).

## Как редактировать без кода

1. Откройте `/admin` на сайте (ссылка есть внизу футера — "Редактор
   контента").
2. Меняйте текст/цены/картинки во вкладках — изменения сразу видны на
   главной странице **у вас в браузере** (сохраняются в `localStorage`).
3. Когда результат устраивает — нажмите **"Экспортировать JSON"**, файл
   скачается на компьютер.
4. Пришлите этот файл (или просто скажите "зафиксируй как есть") — Claude
   Code вставит его как новый дефолт в `src/data/siteContent.js` и запушит.
   После деплоя это увидят уже все посетители сайта, не только вы.

Изменения в `/admin` без экспорта — это черновик, видимый только в вашем
браузере. Чтобы его увидели все, нужен шаг 3–4.

## Формат файла

`docs/content-template.json` в этом же репозитории — актуальный снимок
дефолтного контента (тот же формат, что отдаёт кнопка "Экспортировать").
Можно смело редактировать значения текстом (без правки структуры/ключей) и
прислать обратно, минуя интерфейс `/admin` — просто как черновик наполнения.

Поле `imageUrl` у карточек решений, тарифов и видео-блока — необязательное:
пустая строка `""` означает "используем иконку/плейсхолдер", ссылка на
картинку или загруженный файл (через `/admin`) — использует её вместо
иконки.
