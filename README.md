# mvpMarket

Визуальный прототип маркетплейса товаров: React + Vite + React Router,
без бэкенда — состояние (корзина, избранное, сессия, товары продавца,
заказы) хранится в localStorage.

Архитектура, роуты, роли и план деплоя описаны в
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — документ обновляется при
каждом согласованном изменении в наполнении.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```
